# FinScore AI: Functional and Technical Audit

**Date:** 2026-11-18 · **Scope:** `finscore-ai` monorepo (FastAPI backend, Next.js 14 frontend), working tree including the 20 uncommitted files present on this date.
**Method:** read every doc in `docs/`, mapped all 31 frontend routes and about 100 API endpoints, read the auth, rate-limit, theme, plan and partner code, and ran the app locally (embedded PostgreSQL at migration `0011`, backend `uvicorn` on :8001, existing Next dev server on :3000). I walked through the app in the in-app browser with a throwaway account (`audit.<timestamp>@example.com`) that I created during the audit.
**Not done:** I did not re-run the backend `pytest` or frontend `vitest` suites, did not run Docker or CI, did no load testing and no automated accessibility scan. Every finding below names its evidence.

## 1. Architecture summary (what exists)

| Layer | Implementation | Assessment |
|---|---|---|
| Backend | FastAPI modular monolith, 17 routers, async SQLAlchemy 2, Alembic (11 migrations), import-linter boundaries | Clean and well structured. Calculation engines are pure and use `Decimal`. |
| Calculation | `app/engines/*`: cashflow, debt, growth, retirement, score (20-pillar), matrix_score (15-factor), health, simulate, actions, copilot | Strong. Determinism and additivity are tested (per the tracker). |
| AI | Provider abstraction. `AI_PROVIDER=none` by default; the Anthropic adapter has never been called (K-19) | Every "AI" reply today is a template or keyword rule. |
| Frontend | Next.js App Router, Tailwind, React Query, typed OpenAPI client, same-origin proxy (`next.config.mjs` rewrites) | Good. The proxy design causes SEC-01 below. |
| Background work | In-process schedulers (erasure purge, Wealth OS outbox poller) | Fine on one instance only (K-15, K-41). |
| Tests | 33 backend test files (342 `def test_`), 13 frontend test files, 2 Playwright specs | Good coverage for an MVP. Not re-run in this audit. |
| CI | `.github/workflows/ci.yml`: lint, type, test, pip-audit, npm audit, docker build, e2e | Written. K-12 says it has **never been confirmed green**. |

## 2. Findings

| ID | Module | Perspective | Problem | Evidence | User impact | Business impact | Recommendation | Pri | Effort | Success metric |

| FT-01 | Rate limiting / client IP | Technical | The limiter and audit trail use `request.client.host`. All browser traffic arrives through the Next.js proxy, so every user shares **one** bucket per endpoint. Site-wide caps: 10 registrations per hour, 10 logins per minute, 5 password resets per hour. | `backend/app/infra/ratelimit.py:47`, `backend/app/api/deps.py:44`, `frontend/next.config.mjs` rewrites, `backend/Dockerfile` CMD has no `--proxy-headers`. Settings > Active sessions showed `127.0.0.1` for my browser. | With real traffic, users get "Too many attempts" when signing up or logging in. | Hard cap on growth: 240 signups a day at most. One attacker can block every login with 10 requests a minute. Audit IPs are useless. | Run uvicorn with `--proxy-headers --forwarded-allow-ips=<proxy>`, forward `X-Forwarded-For` from Next, key auth limits on IP **and** email/account, move to Redis before scaling. | **P0** | Low–Med | 0 false 429s in a 1,000-signup load test. Per-IP plus per-account limits verified. |
| FT-02 | Scoring | Product/Tech | **Two different FinScores.** The 20-pillar score (300–900) drives Score, DNA, Actions, Health, Today and the partner API. Doubles build and maintenance cost. | Make the product decision (X-04) and ship **one** score. Feed every module from one fact base. | **P0** | High (decision) / Med (eng) | One score shown everywhere. Every module filled after onboarding. |

## 3. What works well (verified in the browser)
- Registration → email verification → login works end to end (FileMailer). Registration does not reveal whether an email already exists.
- Money Map: chips plus shorthand amounts ("85k", "1.5L"), branching (loan balance asked only when EMIs exist), instant feedback after every answer, and a first score after **9 taps (about 90 seconds)**.
- The Coach's regulated-advice guard correctly declined "Which mutual fund should I buy?" and offered a human.
- Consent gate before AI processing. Data export. Account deletion with password re-confirmation and cooling-off. "Talk to a person".
- Phone layout with a bottom tab bar. Desktop rail. Dark mode toggle.
